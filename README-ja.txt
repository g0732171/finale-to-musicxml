Finale Archive オフライン版 v0.6.2

■ 起動
ZIP全体を展開してください。ZIP内から直接実行しないでください。
Windows 10/11（64ビット）：Start-Windows.cmd をダブルクリック。
macOS 11以降：Start-Mac.command をダブルクリック。
Mac版にはApple SiliconとIntel両方の実行環境を同梱しています。
PythonやFinaleのインストール、インターネット接続は不要です。
既定のブラウザに日本語の画面が開きます。
Macの起動用ファイルはターミナルで実行されます。実行中は閉じず、画面の「終了」で終了してください。

■ 操作
1. 「ファイルを1つ選ぶ」または「フォルダを選ぶ」を押します。
2. システム標準のウィンドウで対象を選択します。パスの入力は不要です。
3. 「MusicXMLに変換する」を押します。
4. 選んだ原本と同じ階層に「元の名前_変換済み」フォルダを新規作成します。
   同名がある場合は _2、_3 と連番を付け、上書きしません。
5. 「保存先フォルダを開く」で結果を確認できます。
   MXL個別ダウンロード、ZIPダウンロード、楽譜プレビューも利用できます。

フォルダ内のサブフォルダ階層とファイル名を保持します。
同名のMUS/MUSXがある場合、出力ファイルにも連番を付けます。
保存先フォルダに作成するのはMXLのみです。CSV、JSON、ログは作成しません。
原本は変更しません。その他の形式やフォルダ内のリンクは処理しません。
アプリの展開先は楽譜の原本フォルダの外に置くことを推奨します。

■ ローカル処理
楽譜の選択・読み取り・変換・保存・プレビューはこのパソコン上で実行します。
外部サーバーへの送信や更新確認、初回の追加ダウンロードはありません。
ブラウザの127.0.0.1アドレスはこのパソコン内の画面です。
終了するには画面右上の「終了」を押し、タブを閉じてください。
操作しないまま30分経過すると、変換・選択中でなければ自動終了します。
再度起動用ファイルを実行すれば再開できます。保存済みMXLは残ります。

■ 対応と制限
MUSXおよび一部の旧MUS形式に対応します。ETFは未対応です。
非常に古いMUSなど、読み取れない世代や構造は「未対応」と表示します。
すべての世代・記号・レイアウトの完全再現を保証するものではありません。
MUSではパート名やピアノの大譜表などが保持されない場合があります。
音符・拍子・調号・移調・記号・大譜表を原譜と照合してください。
1ファイル20 MB、1回5000ファイルまで。1ファイルの変換は最大90秒です。
元のフォルダと同じ階層に書き込みできる必要があります。
保存できない場所にある場合、原本のコピーを「書類」等に置いて選択してください。

■ 検証状況
Windows版は同梱環境でMUS/MUSXの実変換・入力不変・出力内容を検証します。
Mac版は同じアプリコードとMac専用の同梱環境・依存ファイルを使用します。
Mac実機での起動・選択ウィンドウの最終確認は未実施です。

更新 v0.6.2（2026-11-04）
MUSを年号ではなく実際のデータ構造で判別するよう変更しました。
旧式の無圧縮ファイル、異なる譜表データ配置、4つのレイヤーに対応。
削除済み音符・内部用譜表・位置調整された休符の読み取りを修正。
実際の総譜フレームをすべて検証してからMXLを生成します。不明な構造は推測しません。
対応世代、記号、パート名、組版の制限は引き続きあります。
